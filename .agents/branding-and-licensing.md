# 品牌与许可规范

## 统一命名

| 用途 | 名称 |
| --- | --- |
| UI 品牌 | 见字 Jianzi |
| 副标题 | Open-source Calligraphy Font Studio |
| GitHub 仓库 / Tauri 产品 | Jianzi |
| Python 包 | `jianzi_core` |
| CLI | `jianzi` |
| 项目描述文件 | `project.jianzi` |
| 推荐 Bundle Identifier | `com.jianzi.studio` |

品牌字符串必须集中配置，禁止散落硬编码。“Open-source Calligraphy Font Studio”是副标题，不是正式产品名。

## 许可和素材

Jianzi 代码采用 MIT License。README 与发行材料必须说明：Jianzi 软件本身采用 MIT；用户导入的书法作品、碑帖扫描件、数字图像和生成字体的版权与许可取决于原始素材；Jianzi 不自动授予输入素材或输出字体的商业使用权。

仓库不能加入版权不明的高清书法扫描件、网络下载字帖或商业字体图片。测试与演示仅用自制、程序生成或明确 CC0 素材。真实资料可用于本地研发验证，但默认不得提交。
