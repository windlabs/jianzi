# 产品工作流、UI 与版本范围

## 核心流程

```text
导入作品 → 页面处理 → 单字切割 → 原文顺序映射 → 人工校正
→ 字形清理 → 矢量化 → 标准化/异体 → Metrics → OpenType 构建 → 验证
```

V0.1 的切字优先级是网格和人工 bbox，而不是 OCR。网格必须支持行列数、外边界、行线、列线、页边距和实时 bbox 预览。阅读顺序至少支持 `LTR-TTB` 与传统竖排 `RTL-TTB`（右列到左列、列内从上到下）。

Mapping 是一级工作区：粘贴原文后按 glyph `order` 顺序映射 Unicode，并支持确认、修改、跳过、未知、删除、重复、异体、上下一个及高效键盘操作。

## V0.1 验收

范围：创建/打开项目、图片导入与查看、网格切字、bbox 编辑、阅读顺序、文本映射、Glyph Gallery、PNG 导出。不要提前引入云、账号、协作、插件市场、复杂 OCR、AI 完整造字、完整贝塞尔编辑、移动端或 Web 版。

## 后续路线

- V0.2：阈值、去背景、清理、Normalize、批处理、Potrace、SVG、质量评分。
- V0.3：Font Profile、Metrics、FontForge、TTF、fontTools、验证和报告；以 2×4 的“天地玄黄宇宙洪荒” fixture 打通安装可显示的 TTF。
- V0.4：异体、性能优化、subset、OTF、WOFF2、问题定位。
- V0.5：自动行列检测、OCR 插件、SVG 高级编辑、OpenType alternates。
- V1.0：稳定 Windows 发布版、长期项目兼容和完善文档。

## UI 原则

中文优先、现代、克制、专业，并为英文、深浅主题与高 DPI 预留。布局可参考专业工作台：左侧项目/作品/页面/字形/映射/字体/构建导航，中间 workspace，右侧属性，底部任务状态。可以使用墨色和少量朱砂作为强调色；禁止仿古卷轴、重度宣纸背景或影响效率的装饰动画。
